# MAK

MAK (Mój Akademicki Kalendarz) to lokalna aplikacja na Androida do planu zajęć, także przy kilku kierunkach. Działa offline, bez kont i chmury.

Po konfiguracji semestru korzystasz głównie z ekranu **Dzisiaj** i widgetu. **Plan** pokazuje tydzień jako listę albo kalendarz, z tygodniami A/B i filtrem kierunku.

Aplikacja wykrywa kolizje, liczy okienka, pozwala odwołać, zmienić albo przenieść pojedynczy termin i trzyma notatkę do zajęć osobno od notatki na dany dzień. Kopia zapasowa to plik JSON. Powiadomienia o kolizjach są opcjonalne.

Szczegóły projektu i dokumentacja: [docs/MAP.md](docs/MAP.md).
